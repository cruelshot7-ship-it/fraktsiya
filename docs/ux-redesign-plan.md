# UX/UI-редизайн мини-аппа «Фитнес Фракция»: аудит, структура, план

Основание: ТЗ «UX/UI-редизайн Telegram Mini App» (этапы 1–9) и концепт экранов.
Файл `AGENTS.md`, на который ссылается ТЗ, в репозитории отсутствует. Ориентиры: правила проекта из сессии и чек-лист соответствия законодательству РБ.

Принцип: один экран — одна главная задача; один главный CTA; дополнительное — по запросу.

## Этап 1. Аудит (без изменений кода)

Экраны клиента до редизайна: Сегодня, Программа, Запись (расписание, слоты, записи), Питание, Форма, Зал, Ещё (меню).
Экраны тренера до редизайна: Сегодня, Клиенты (карточка клиента), Расписание, Сигналы, Программы.

Проблемы, найденные в коде:

| # | Экран | Проблема | Серьёзность |
|---|-------|----------|-------------|
| A1 | Клиент · Сегодня | Нет приветствия (первый пункт приоритета ТЗ). Подпись «Запись · тренировка · еда» повторяет названия блоков ниже | средняя |
| A2 | Клиент · Сегодня | Блоки пронумерованы «1 · Запись», «2 · Тренировка» — лишняя служебная структура | низкая |
| A3 | Клиент · навигация | 6 разделов в меню «Ещё»: «Форма» и «Записи и баланс» дублируют вкладки | высокая |
| A4 | Клиент · Прогресс | Вкладки «Форма»/замеры/вес были разнесены по меню | высокая |
| A5 | Тренер · Сегодня | Подпись «Явка · заявки · внимание» повторяет заголовки блоков. «Занятия» (баланс, оплаты) стоят выше «Внимания» | высокая |
| A6 | Тренер · карточка клиента | Оплаты стоят выше баланса; «Последний отчёт» внизу, хотя это главный сигнал | средняя |
| A7 | Клиент · Программа | Экран длинный: «Цикл», «Повторный максимум», «Сожжено» на одной странице. Главный CTA «Завершить подход» есть, но дополнительные блоки не свёрнуты | средняя, не закрыто в этом PR |
| A8 | Тренер · карточка | Вес и КБЖУ показываются без проверки согласия клиента | высокая, закрыто PR #143 (отдельно) |
| A9 | Политика | Текст политики называет пункт меню «Ещё». Исправление требует поднять `PRIVACY_VERSION` | низкая, решение владельца |

Не аудировано в этой итерации: «Запись» (слоты, список записей), «Сигналы», «Программы», экран «Зал». Их проверка — следующий этап.

## Этап 2. Структура интерфейса

Клиент (5 вкладок): Сегодня · Программа · Запись · Прогресс · Профиль.
- Питание — плитка на «Сегодня», не отдельная вкладка (как в концепте).
- «Профиль» содержит: Политика конфиденциальности, Мои данные, Зал, Написать тренеру.
- Самочувствие (форма) — внутри «Прогресса», не в меню.

Тренер (5 вкладок, текущая): Сегодня · Клиенты · Расписание · Сигналы · Программы.
- Гипотеза ТЗ (Главная · Клиенты · Расписание · Сообщения · Ещё) не принята: «Сигналы» и «Программы» — рабочие разделы, их слияние — решение владельца.

## Этап 3. План по экранам

Для каждого экрана: проблема → решение → что видно → что перемещено → что скрыто → навигация → как проверить.

**Клиент · Сегодня** (A1, A2)
- Проблема: нет приветствия; подписи повторяют блоки; нумерация.
- Решение: подпись «{Имя}, что нужно сделать сегодня?» (вопрос из ТЗ); блоки без номеров.
- Видно: баланс, запись, тренировка, питание-плитка.
- Перемещено: ничего. Скрыто: ничего.
- Проверка: открыть вкладку «Сегодня», увидеть имя и вопрос; тренировка — один CTA.

**Клиент · навигация** (A3, A4)
- Проблема: дубли в меню.
- Решение: «Форма» → «Прогресс» (блок «Самочувствие»); «Записи и баланс» → вкладка «Запись»; «Профиль» — только настройки и связь.
- Проверка: из «Прогресса» открыть форму; из «Профиля» пункты «Политика», «Мои данные», «Зал», «Написать тренеру».

**Клиент · Прогресс** (A4)
- Проблема: экран собирает всё сразу.
- Решение: вес с динамикой за 7 дней (только при согласии); замеры; самочувствие. Без нескольких графиков рядом.
- Скрыто без согласия: вес и замеры — подсказка, как получить согласие.

**Клиент · Программа** (A7)
- Видно: название дня, «Я на месте» (до тренировки), список подходов, «Завершить подход» (главный CTA).
- Перемещено/скрыто: «Цикл», «Повторный максимум», «Сожжено» — вторичны. Сворачивание в «Дополнительно» — в следующем PR, так как меняет вёрстку большого файла.

**Тренер · Сегодня** (A5)
- Порядок: статистика смены → «Отметить явку» → «Заявки в зал» → «Внимание» → «Занятия» (баланс, оплаты).
- Подпись: «Что требует внимания сегодня?».

**Тренер · карточка клиента** (A6, A8)
- Порядок: программа → последний отчёт → баланс → оплаты → питание и вес.
- Вес и КБЖУ без согласия — отдельный PR #143.

## Критерии приёмки (ТЗ, раздел 12)

| № | Критерий | Статус |
|---|----------|--------|
| 1 | Каждый экран — очевидная главная задача | частично: клиент «Сегодня» и тренер «Сегодня» — да; «Запись», «Сигналы», «Программы» не аудированы |
| 2 | Основное действие легко найти | да на «Сегодня» и в тренировке |
| 3 | Информация логично сгруппирована | да для изменённых экранов |
| 4 | Нет бессмысленных повторений | исправлено на «Сегодня» клиента и тренера |
| 5 | Нет декоративных элементов | частично; свечение акцентных блоков не пересмотрено |
| 6 | Основные действия без лишних переходов | да: тренировка — на одном экране |
| 7 | Существующий функционал сохранён | да: перенос, без удалений; «Форма» и «Записи» доступны с новых мест |
| 8 | Клиентская и тренерская навигация разделены | да |
| 9 | Работает внутри Telegram | не проверено: нужна проверка на устройстве |
| 10 | Состояния загрузки/ошибок/пусто | не аудировано по экранам |
| 11 | Результаты тренировок сохраняются | без изменений (логика не трогалась) |
| 12 | Нет горизонтального скролла | не проверено: нужна проверка на телефоне |
| 13 | Нет перекрытия системными областями | не проверено: нужна проверка на устройстве |
| 14 | Автоматические проверки пройдены | да: синтаксис, 233 lib-теста, список тестов, CI `check` |
| 15 | Сборка проходит | да: CI зелёный, превью Vercel собран |

Вопрос ТЗ «Может ли новый пользователь понять, что делать дальше, без объяснений тренера?» — для клиентского «Сегодня» да; для «Программы» и «Записи» требует проверки на устройстве.

## Открытые решения владельца

1. Текст политики «Ещё → Профиль»: поднимать `PRIVACY_VERSION` или нет.
2. «Сигналы»: оставить вкладкой или свернуть в «Сегодня».
3. PR #143 (согласие на данные о здоровье): мержить отдельно или вместе с #144.
4. Сворачивание блоков «Программы» (A7) — делать ли в этом PR или следующим.
