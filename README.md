# Фракция — фитнес mini app

Telegram Web App студии «ФИТНЕС ФРАКЦИЯ»: запись, баланс занятий, КБЖУ, сигналы тренера, лист ожидания, чек-ин.

## Правила занятий

- Тренер зачисляет пакет: +1 / +4 / +8 / +12.
- Запись бронирует 1 занятие.
- Отмена раньше чем за 2 часа — занятие возвращается.
- Отмена меньше чем за 2 часа — занятие **сгорает**.
- Отмена тренером — всегда возврат + уведомление клиенту.

## Railway

1. [railway.app](https://railway.app) → New Project → Deploy from GitHub → `cruelshot7-ship-it/fraktsiya`.
2. Dockerfile уже в репо. Порт `8080`.
3. Переменные пока не нужны (демо на localStorage).

Кнопка Web App в боте: укажите URL после деплоя.
